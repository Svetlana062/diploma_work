# diploma_work

Платформа для публикации платного контента

## Описание:

Реализована платформа для публикации записей пользователями. Публикация 
может быть бесплатной, доступной любому пользователю без регистрации, 
либо платной, доступной только авторизованным пользователям, которые 
оплатили разовую подписку. Для реализации оплаты подписки использован 
Stripe. Регистрация пользователя осуществлена по номеру телефона. 
Платформа имеет фронтенд в виде шаблонов с использованием Bootstrap.

### Основные возможности:

* Аутентификация по номеру телефона;
* Создание, просмотр, редактирование и удаление записей;
* Бесплатные и платные публикации;

### Требования к окружению

* Python 3.13+
* Poetry для управления зависимостями
* PostgreSQL (рекомендуется) или SQLite
* Docker и Docker Compose (для запуска в контейнерах)

## Установка и запуск локально

1. Клонируйте репозиторий:

    ```bash
    git clone https://github.com/Svetlana062/diploma_work.git
    ```

2. Активируйте виртуальное окружение (рекомендуется использовать Poetry):

    ```bash
    poetry shell
    ```

3. Установите зависимости:

    ```bash
    poetry install
    ```

4. Создайте файл `.env` на основе `.env.example` и заполните необходимые переменные окружения.

5. Выполните миграции базы данных:

    ```bash
    python manage.py migrate
    ```

6. Запустите сервер разработки:

    ```bash
    python manage.py runserver
    ```

Сервер будет доступен по адресу: http://localhost:8000/

### Запуск на удаленном сервере с Docker

1. Убедитесь, что на сервере установлен Docker и Docker Compose; 
2. Создайте файл .env в корневом каталоге проекта, если он еще не создан, 
и добавьте необходимые переменные окружения.

3. Соберите и запустите контейнеры:
    ```
    docker-compose up --build -d
    ```
   
Приложение будет доступно по адресу: http://your_domain_or_IP:8000/

## Настройка CI/CD:

Проект использует GitHub Actions для автоматизации CI/CD. Файл
конфигурации находится по пути: .github/workflows/ci.yml.

При каждом push или pull request запускаются тесты на сервере с
использованием PostgreSQL, а также происходит сборка и развертывание
приложения.


## Структура проекта

Проект содержит два Django-приложения:

### users (реализует управление пользователями)

* Модель пользователя (CustomUser) с полями для авторизации по номеру телефона и ролью
администратора (`users/models.py`);
* Миграции (`users/migrations/`);
* Команда для создания суперпользователя (`users/management/commands/csu.py`);
* Сериализаторы API (`users/serializers.py`);
* Формы для регистрации и входа (`users/forms.py`);
* ViewSet для API (`users/views.py`);
* Разграничение прав доступа (`users/permissions.py`).

### entries (реализует управление записями)

* Модель для записей Entry (`entries/models.py`);
* Миграции (`entries/migrations/`);
* Сериализаторы API (`entries/serializers.py`);
* ViewSet для API записей (`entries/views.py`);
* Утилиты проверки подписки (`entries/utils.py`);
* Маршруты API и HTML (`entries/urls.py`).

# diploma_work
Название дипломного проекта: Платформа для публикации платного контента

## Описание:

Реализована платформа для публикации записей пользователями. Публикация 
может быть бесплатной, доступной любому пользователю без регистрации, 
либо платной, доступной только авторизованным пользователям, которые 
оплатили разовую подписку. Для реализации оплаты подписки использован 
Stripe. Регистрация пользователя осуществлена по номеру телефона. 
Платформа имеет фронтенд в виде шаблонов с использованием Bootstrap.

### Основные возможности:

* Аутентификация по номеру телефона;
* Создание, просмотр, редактирование и удаление записей;
* Бесплатные и платные публикации;


### Требования к окружению

* Python 3.13+


## Установка

* Клонируйте репозиторий:
```
git clone https://github.com/Svetlana062/Python_Project_5_Django.git
```

* Установите зависимости:
```
pip install -r requirements.txt
```

* Войдите в виртуальное окружение:
```
poetry shell
```

* Выполните миграции базы данных:
```
python manage.py migrate
```

* Запустите сервер разработки:
```
python manage.py runserver
```

API будет доступен по адресу: http://localhost:8000/


### Запуск на удаленном сервере

1. Настройте сервер:
* Убедитесь, что на сервере установлен Docker и Docker Compose;
* Создайте файл .env в корневом каталоге проекта, если он еще не создан, 
и добавьте необходимые переменные окружения.

2. Соберите и запустите контейнеры:
```
docker-compose up --build -d
```
Теперь приложение доступно по адресу: http://your_domain_or_IP:8000/

### Инструкция по настройке CI/CD

Настройка CI/CD:
* Проект использует GitHub Actions для автоматизации CI/CD. Файл
конфигурации находится по пути: .github/workflows/ci.yml;
* При каждом push или pull request запускаются тесты на сервере с
использованием PostgreSQL, а также происходит сборка и развертывание
приложения.


## Структура проекта
Данный проект содержит два Django-приложения:

1. users (реализует управление пользователями):
* Модель пользователя (CustomUser) с полями для авторизации по номеру телефона и ролью
администратора (users/models.py);
* Миграции базы данных (users/migrations/);
* Команда для создания суперпользователя (users/management/commands/csu.py);
* Сериализатор модели пользователя для API (users/serializers.py);
* Формы для регистрации, входа и создания новых пользователей (users/forms.py);
* ViewSet для работы с пользователями через API (users/views.py);
* Разграничение прав доступа - permissions (users/permissions.py).

2. entries (реализует управление записями):
* Модель для записей Entry (entries/models.py);
* Миграции базы данных (entries/migrations/);
* Сериализатор для API (entries/serializers.py);
* ViewSet для API записей (entries/views.py);
* Проверка есть ли у пользователя подписки((entries/utils.py));
* Маршруты API и HTML (entries/urls.py).

Дополнительно
В проекте также присутствует файл .env.example, содержащий список необходимых переменных
окружения для настройки проекта.
